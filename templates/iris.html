Quick actions

Connect a phone (ADB)

  1. On the phone: Settings → About phone → tap Build number 7× to unlock Developer options, then enable USB debugging (and Wireless debugging for Wi-Fi mode).
  2. On the computer running IRIS (not a Vercel server — ADB needs a local host): install the platform tools, e.g. sudo apt install adb (Linux/WSL) or download Android platform-tools for Windows/macOS.
  3. USB mode: plug the phone in, accept the “Allow USB debugging?” prompt, then scan here:
  4. Wireless mode (same Wi-Fi): first connect over USB once and run adb tcpip 5555, then find the phone's IP (Settings → About → Status) and connect:
  5. Multiple phones? Set ADB_DEVICE_ID to the id from the scan (e.g. ADB4C1F0E…) so IRIS targets the right device.
